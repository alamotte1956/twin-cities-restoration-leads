# Twin Cities Restoration Lead Prototype — README

## What this is
A Flask prototype that captures exclusive water damage, mold, and indoor air quality leads and routes them to one primary Twin Cities restoration contractor.

## Services
- Water damage restoration
- Dry out services
- Mold mitigation
- Mold inspection
- Mold remediation
- Indoor air quality testing

## How to run
```bash
cd /workspace/artifacts
python3 gc_lead_prototype.py
```
- Form: http://localhost:5000
- Dashboard: http://localhost:5000/dashboard

## Features
- Multi-field qualification form
- Urgency-weighted scoring + priority ZIP boost
- Exclusive assignment to one contractor
- Status workflow with dropdown updates
- In-memory storage (restart clears data)
